Paper numbers: 1 µs syndrome cadence (Section 1), 24 ns per BP iteration and ~20 iterations average to converge at p = 10⁻³ (Section 7, Figure 8b), so 480 ns per 12-cycle window decode — ~40 ns average per syndrome cycle — on a 4 ns FPGA clock with 12 ns decoder cycles (Figure 5). The decode finishes ≈520 ns before the next syndrome batch arrives: the decoder keeps up with the QPU with margin to spare, the paper's headline real-time claim.

The sliding window (bottom) uses W = 12, fixed to the bare code distance (Section 4.1). The commit/carry split C = 6 is illustrative — any 1 ≤ C < W is valid and the paper doesn't fix it (Section 4.1, Appendix D, Algorithm 2). The detector-processing latency in the second lane is also illustrative.
